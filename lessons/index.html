从会运行，到会设计实验

这套路径围绕一条真实工作流展开：本地理解与修改 → Git 固化实验身份 → GPU 服务器训练 → 取回指标与 rollout → 用证据决定下一次单一改动。

阶段你将获得的能力状态
1. 参数到证据识别任务/模型/算法/运行四层参数，建立可复现实验闭环现在开始
2. 环境闭环沿 61 维观测 → 14 维动作 → 物理步进 → reward 逐行走读完成第 1 课练习后生成
3. 三种算法横向 diff REINFORCE、A2C、PPO，解释每个新增机制解决什么失败待学
4. 读懂一次 run区分训练健康度、任务成绩与行为质量；补齐分项诊断日志待学
5. 第一次受控实验完成 baseline/variant、相同评估、结果摘要与复现实验卡待学
6. 调参而不乱试按症状提出假设，设计单变量/多 seed 实验与停止条件待学
7. 设计新任务定义接口、奖励、终止、课程表、域随机化和不可被钻空子的成功判据待学
8. 迁移项目把 PPO 实验方法迁移到一个由你选择的新动作、机器人或控制问题待确定目标
节奏：每课只有一个可验证成果。你提交练习答案后，我会记录已掌握的能力，再生成处于“刚好有挑战”区间的下一课。

课程不是固定讲义目录。第 2 课的深度会依据你对第 1 课五个问题和实验卡的回答调整。
