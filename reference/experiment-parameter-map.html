最常调的当前值

参数当前值作用首先观察
NUM_ENVS4096每个控制步并行多少个世界；主要影响吞吐和每轮样本量墙钟吞吐、显存、是否 OOM
MAX_ITERATIONS6000外层采样—更新次数是否越过相关 curriculum 阶段
num_steps_per_env24每轮每个环境采样长度batch 大小、curriculum 步数换算
gamma0.99未来奖励折扣return/value 尺度、长短期行为
lambda0.95GAE 偏差—方差旋钮优势噪声、value 依赖
clip_param0.2限制策略概率比的有效更新范围KL、policy loss、行为退化
entropy_coef0.01鼓励探索entropy 是否过早塌缩
learning_rate1e-3Adam 初始步长，随后按 KL 自适应KL 与实际 lr
desired_kl0.01自适应学习率的目标变化尺度KL 是否长期高于 .02 或低于 .005
learning epochs × minibatches5 × 4同一 rollout 产生 20 次优化 step样本复用、KL 增长、墙钟

指标不要误读

字段可以说明不能单独说明
reward当前环境评分的每步均值是否变化目标动作是否真的发生、是否自然、是否泛化
entropy动作分布的随机探索强弱策略质量高低
KL一次更新把策略推了多远任务是否学会
value losscritic 对当前 returns 的拟合误差跨 curriculum、跨 reward 配方的绝对优劣
policy loss当前 batch 上 surrogate objective 的优化状态可直接比较的“成绩”
视频/关键帧动作形态、投机行为、失败模式大量随机条件下的成功率

一次实验的最小证据包

  • 精确 commit、task、seed 和完整命令
  • 基线与实验使用相同评估指令
  • 训练曲线与最终/中间 checkpoint
  • 确定性 rollout 的数值结果和视频
  • 事前预测、观察事实、是否支持假设
