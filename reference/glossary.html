RL Duck 术语表

同一个词在不同项目里可能指不同东西。这里固定本课程的用法，后续课程都遵守这张表。

术语本课程中的精确定义本仓落点
task环境配置与训练配方在注册表中的名字，不等于一次实验。TASK / task ID
state仿真世界的完整状态；策略通常看不到全部。MuJoCo/Mjlab 内部
observation策略或 critic 每一步实际收到的数值。actor 与 critic 可以不同。cfg.observations
action策略输出并交给环境执行的 14 维目标量。cfg.actions
reward单个控制步的标量评分；常由多个加权 term 相加。cfg.rewards
return从某一步起的折扣累计奖励，是价值函数与策略优化使用的长期量。reward_to_go / compute_gae
episode从 reset 到终止或超时的一段完整交互。episode_length_s
rollout用当前策略收集的一批连续交互数据，不必等于完整 episode。sample_rollout()
iteration本仓中一次“采 24 步 × N 环境，再更新”的外层循环。Lightning 的一个 epoch
learning epochPPO 对同一 rollout 重排并复用一次；本仓默认 5 次。num_learning_epochs
checkpoint模型、优化器、迭代号和部分训练设置的快照。model_N.pt
curriculum随环境步数分阶段改变任务难度或奖励权重的规则。cfg.curriculum
domain randomization训练时随机改变质量、摩擦、传感器偏差等物理或观测条件。cfg.events
seed伪随机过程的起点；换 seed 就是一次不同的随机实验。RL_DUCK_SEED
ablation只移除或改变一个机制，以判断它是否造成观察到的效果。实验设计方法

有术语不清楚时，直接问你的教学助手；确认后把定义补进此表。
